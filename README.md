## 上传方式

将本文件夹中的 `index.html`、`question-bank.js`、`README.md`、`stats-config.js`、`supabase-setup.sql` 上传并覆盖仓库根目录同名文件，提交到 `main` 分支。等待 Actions 中 `pages build and deployment` 变为绿色后，打开网页并 Ctrl+F5 强制刷新。

注意：`question-bank.js` 必须和 `index.html` 一起上传，否则网站会只加载旧的内置基础库。
